# F-011 — EXIT §6 delays exit "to prevent cascading instability"; SCOPE §9 forbids delays for stability goals

**Classification:** CONFIRMED_FINDING (kind `contradiction`), resolved by an explicit priority rule
(SCOPE §2).  Revised after review (2026-10-08): the lab now applies the resolution instead of reporting a
reference FAIL.  Open question Q-031 (rephrased).
**Found by:** module `exit_integration` (S-LAB-07).  **Regression:** `tests/lab/test_findings.py`,
`tests/lab/test_exit_integration_module.py::test_reference_breaks_no_rule`.

## Analysis

| | EXIT §6 | SCOPE §9 |
|---|---|---|
| Text | "Exit execution occurs after a fixed cooling period, calibrated exclusively under DKP-8-SIMULATION-001." / "The cooling period exists to: prevent cascading instability, allow settlement of restitution tails, enable orderly disengagement, protect non-exiting parties from abrupt dependency loss." | "exit SHALL NOT be delayed for optimization or stability goals," |
| Subject, object | exit execution; a delay | exit; a delay |
| Scope, conditions | every exit, always | every exit; a delay *for* optimization or stability goals |
| Modality | obligation (a mandatory delay), with a stated stability purpose | prohibition |

**Joint compliance:** impossible as written — the mandatory delay serves, in EXIT's own words, a stability
goal.  **Priority:** SCOPE §2: "In case of conflict, DKP-7-SCOPE-001 prevails."  **Result:** the stability
purpose of the cooling period is inoperative; a cooling period may still serve the other purposes.

What remains open: whether "protect non-exiting parties from abrupt dependency loss" is itself a
stability goal.

## What the lab does (module 1.1.0)

The input `cooling_purposes` (hypothesis H-EI-4, source `text`) lists the purposes the cooling period
serves.  The default is the EXIT §6 list without "prevent cascading instability", which SCOPE §2/§9 set
aside.  SCOPE-9-02 then gives:
- UNKNOWN while dependency protection is among the purposes;
- PASS for settlement and orderly disengagement only;
- FAIL when the stability purpose is kept (alternative example `cooling_for_stability`).

The cooling length itself has no value in the corpus (H-EI-1).
