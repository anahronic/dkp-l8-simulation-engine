# F-043 — CRISIS §12.1 propagates PTL confidence; §12.3 forbids SUFFICIENT_DATA for axiom interpretations

**Classification:** CONFIRMED_FINDING (kind `contradiction`, effect `changes_execution`).  Open question Q-063; hypothesis H-CR-6.
**Found by:** module `crisis_recovery`.  **Regression:** `tests/lab/test_findings.py::test_f043_crisis_confidence`.

## Verification against the pinned text

| Place | Literal text |
|---|---|
| CRISIS §12.1 | "All Crisis outputs SHALL carry: … - confidence_state: as propagated from triggering PTL signals" |
| CRISIS §12.2 | "Outputs that interpret "minimum required conditions" under Axiom A1 SHALL additionally carry:" |
| CRISIS §12.3 | "Crisis outputs SHALL NOT carry validity_state: VALID or confidence_state: SUFFICIENT_DATA for any determination that constitutes interpretation of axiom application." |
| EPISTEMIC-BOUNDARIES §5 | confidence states "- SUFFICIENT_DATA", "- INSUFFICIENT_DATA", "- DEGRADED_SIGNAL" |

## Analysis

| | Rule A: CRISIS §12.1 | Rule B: CRISIS §12.3 |
|---|---|---|
| Subject | every Crisis output | Crisis outputs that interpret axiom application |
| Object | `confidence_state` = the value propagated from the triggering PTL signals | `confidence_state` SUFFICIENT_DATA (and `validity_state` VALID) |
| Scope | all crisis outputs, the §12.2 outputs included | axiom-interpreting determinations, among them the §12.2 A1 minimum-conditions outputs |
| Conditions | always | always |
| Modality | obligation | prohibition |

**Joint compliance:**
- Impossible for an axiom-interpreting output when the triggering PTL confidence is SUFFICIENT_DATA.
- Possible when that confidence is DEGRADED_SIGNAL or INSUFFICIENT_DATA.
- The VALID half of §12.3 is always satisfiable: §12.1 fixes `validity_state` to CONDITIONAL.

**Priority:** none stated.
- §12.3 is narrower, but the corpus states no rule that the specific provision prevails, and the lab does not apply one.
- §12.3 states its purpose (non-precedent) but names no replacement value.
- EB §5 offers only SUFFICIENT_DATA, INSUFFICIENT_DATA and DEGRADED_SIGNAL.  Any value other than the propagated one misstates the data.

**Result:** a contradiction, under one condition: an axiom-interpreting crisis output resting on SUFFICIENT_DATA PTL signals.

## Effect

Every crisis output that rations to the survival minimum interprets A1 (H-CR-4).  In the lab's reference runs such outputs rest on confirmed PTL signals, so each one breaks §12.1 or §12.3.  A literal implementation cannot satisfy both until the author decides.

## Question (Q-063)

Which `confidence_state` does an A1 (axiom-interpreting) crisis output carry when the PTL data are sufficient?  The options are:
- keep the propagated value (amend §12.3);
- name another value (amend §12.1 or §12.3);
- emit no such output.
