## Analysis

| | Rule A (Code A.1) | Rule B (ORACLE §12) |
|---|---|---|
| Subject | all Kill Switches | B(t) |
| Object | activation (disconnection from infrastructure, §8.1) | triggering enforcement |
| Scope | the Network | every consumer of B(t) |
| Conditions | B(t) < 0.68 | no attached and valid L8 calibration bundle |
| Modality | obligation, automatic ("activate simultaneously") | prohibition ("SHALL NOT trigger enforcement") |

- **Joint compliance.** Impossible when B(t) < 0.68 and no valid bundle exists.  Possible once a bundle
  is attached.
- **Priority.** No text ranks the Code against ORACLE.  ORACLE calls itself "an integral extension of
  Appendix A.2", not of A.1.  Code A.1a sends parameter changes through SIMULATION but does not make
  the A.1 trigger depend on a bundle.
- **Result.** A contradiction, conditional on the absence of a bundle, which is the present state of
  the corpus.
