## Analysis

| | Rule A (Code §18.1) | Rule B (LABOR §9.1 with §3.1; PRIVACY §10) |
|---|---|---|
| Subject | every UBR recipient (by §17.1, every human) | every Subject; the system |
| Object | participation in education, creativity or socially useful activity; a rating for additional benefits | participation in labor, which includes creative and social activity; social credit scoring and behavioral profiling |
| Scope | always | outside declared crisis (LABOR); always (PRIVACY) |
| Conditions | receipt of UBR; total passivity | none |
| Modality | obligation; automatic reduced rating | no compulsion, refusal triggers no punishment; prohibition |

- **Joint compliance.** UBR itself stays unconditional, so LABOR §4.1 holds; the lab checks it.
  Beyond that, both rules hold only if the reduced rating for *additional* benefits is neither
  "punishment" for refusing participation nor "social credit scoring" or "behavioral profiling".  None of
  these terms is defined.  Note that Code §15.1 presumes that a "social rating" exists.
- **Priority.** No text ranks the Code against LABOR or PRIVACY.
- **Result.** It depends on the reading.
