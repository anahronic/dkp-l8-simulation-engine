# F-025 — Axiom A4 says SHOULD, while every axiom is a constraint

**Classification:** INTERPRETATION_GAP (semantic verification 2026-10-07).  Open question Q-044.
**Found by:** module `axiom_constraints`.  **Regression:** `tests/lab/test_findings.py`,
`tests/lab/test_axiom_constraints_module.py::test_a4_readings`.

## Verification against the pinned text

| Place | Literal text |
|---|---|
| AXIOMS A4 | "System actions SHOULD minimize irreversible damage when reversible alternatives exist." |
| AXIOMS A4 | "Irreversible transitions require demonstrable necessity verified by irreversible impact models under DKP-1-IMPACT." |
| AXIOMS §3 | "Each axiom is defined as: - a forbidden state, or - a hard priority ordering between competing system objectives." |
| AXIOMS §5 | "2. Violation of any axiom invalidates an action regardless of utility score" |

Every other axiom uses MUST, SHALL or "forbidden"; A4 alone uses SHOULD.  Read as a constraint (§3, §5), an
irreversible action without verified necessity is invalid when a reversible one exists; read as a
recommendation, it may be chosen.  The second sentence ("require demonstrable necessity") is mandatory, but
IMPACT contains no "irreversible impact models" (IMPACT §7 lists illustrative criteria only), so necessity can
only be declared.
