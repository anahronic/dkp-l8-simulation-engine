# F-006 — The polarity of Rᵢ is not fixed by IMPACT

**Classification:** INTERPRETATION_GAP (semantic verification 2026-10-07; formerly recorded as a
cross-protocol defect — withdrawn, see "Verification").  Open question Q-022 (rephrased).
**Found by:** module `dispute_correction` (S-LAB-04).  **Regression:** `tests/lab/test_findings.py`,
`tests/lab/test_dispute_correction_module.py::test_r_polarity_matters_only_when_mixed`.

## Verification against the pinned text

| Place | Literal text | What it fixes |
|---|---|---|
| IMPACT §4 | "#### Reversibility Flag Rᵢ" / "A boolean indicator of physical or informational irreversibility." | that Rᵢ is boolean and concerns (ir)reversibility; **not** which value means which |
| IMPACT §7 | "binary in output." | binary output, no polarity |
| IMPACT §10 | "**Rᵢ** — reversibility flag," | the name only |
| IMPACT §13 (non-normative) | "Rᵢ = False" for a +0.09 ppm CO₂ change | an illustration; "This example is illustrative only and not normative." |
| JUSTICE §3.1 | "Rᵢ — reversibility flags," | received from IMPACT |
| JUSTICE §6 | "impact is reversible (Rᵢ = True), and" | **True = reversible** |
| JUSTICE §8 | "impact is irreversible (Rᵢ = False), or" | **False = irreversible** |

The earlier record read "indicator of … irreversibility" as "True = irreversible".  The text does
not say that: the field is named a *reversibility* flag and the sentence names only the property it
indicates.  The only explicit polarity in the corpus is JUSTICE §6/§8, and nothing normative in
IMPACT contradicts it.  The §13 example (Rᵢ = False for a small CO₂ change) reads naturally only under
the opposite polarity, but it is non-normative.  So this is not a contradiction between two norms; it
is a semantic gap: IMPACT defines a flag without its polarity, and the polarity has to be taken from
the consumer.

## Effect on a deterministic implementation (revised after review, 2026-10-08)

The review pointed out that an alternative must not be validated by a check that switches the normative
meaning together with the alternative.  The checks are now separate and fixed:

| Check | What it tests, independent of the declared polarity |
|---|---|
| JUSTICE-6-01 / JUSTICE-8-01 | the domains JUSTICE applied, against the flag it **received**, read literally: Rᵢ = True reversible (§6), Rᵢ = False irreversible (§8) |
| IMPACT-11-01 | the flag JUSTICE received is the flag IMPACT emitted: no conversion between the modules ("No higher-layer protocol may: … override reversibility or externality flags", IMPACT §11) |
| JUSTICE-3.1-01 | the interface contract: the emitted flag, read with the only polarity the corpus states (JUSTICE §6/§8), equals the declared physical reversibility |

Each Justice decision records the emitted flag, the received flag, how the adapter read it and the
contract.  `python -m lab run lab/findings/F-006.request.json --out f006.zip` — the §13 input, no other
trigger, three polarities (`r_polarity`, H-DC-5):

| Variant | Physically irreversible | Rᵢ emitted = received | Read as | Restitution | Isolation | FAIL |
|---|---|---|---|---|---|---|
| `reversible_justice_polarity` (default) | no | True | reversible | yes | no | — |
| `irreversible_justice_polarity` | yes | False | irreversible | no | yes | — |
| `reversible_impact_name_polarity` | no | False | reversible | yes | no | JUSTICE-3.1-01, JUSTICE-6-01, JUSTICE-8-01 |
| `irreversible_impact_name_polarity` | yes | True | irreversible | no | yes | JUSTICE-3.1-01, JUSTICE-6-01, JUSTICE-8-01 |
| `reversible_mixed` | no | False | irreversible | **no** | **yes** | JUSTICE-3.1-01 |
| `irreversible_mixed` | yes | True | reversible | **yes** | **no** | JUSTICE-3.1-01 |

- Only the JUSTICE polarity used throughout (the lab default) satisfies JUSTICE §6/§8 and the flag contract.
- A uniform opposite polarity gets the physical outcome right but is not a literal execution of JUSTICE:
  its JUSTICE adapter treats Rᵢ = True as irreversible.
- A mixed chain keeps JUSTICE literal on what it receives, but the flag means the opposite of what IMPACT
  intended, so restitution and isolation swap.
- Counterexample `override_flag`: JUSTICE inverts the received flag.  IMPACT-11-01 fails; JUSTICE acts
  correctly on what it received.

The finding stays an INTERPRETATION_GAP: IMPACT's local contract lacks the polarity that its only consumer
states.

## Question (Q-022, rephrased)

Should IMPACT state the polarity of Rᵢ explicitly (as JUSTICE §6/§8 do), and is the §13 example
output "Rᵢ = False" intended for a reversible change?  No protocol text is changed by the lab; whether
such a clarification is presentation-only (DKP-4-UPGRADE-001 §3) is the author's call.
