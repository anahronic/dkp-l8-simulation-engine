# F-006 — Rᵢ means "irreversible" in IMPACT and "reversible" in JUSTICE

**Status:** UNRESOLVED — cross-protocol defect (open question Q-022).
**Found by:** module `dispute_correction` (S-LAB-04).  **Regression:** `tests/lab/test_findings.py`, `tests/lab/test_dispute_correction_module.py::test_r_polarity_changes_the_domains`.

## Minimal reproduction

```
python -m lab run lab/findings/F-006.request.json --out f006.zip
```

The §13 example input of IMPACT (a tiny, reversible CO₂ change), no other trigger.

| Variant | Physically irreversible | Rᵢ emitted by IMPACT | JUSTICE reading | Restitution | Isolation |
|---|---|---|---|---|---|
| `as_written` | no | False | Rᵢ = False → "irreversible" | no | **yes** |
| `irreversible_as_written` | yes | True | Rᵢ = True → "reversible" | **yes** | **no** |
| `consistent` (alternative) | no | False | read as IMPACT defines it | yes | no |

Read as written, the chain inverts JUSTICE: a small reversible change is isolated, an
irreversible one only gets restitution.

## Chain of provisions

- IMPACT §4 (IMPACT-ReversibilityFlagR_-01) — "**Reversibility Flag Rᵢ** A boolean indicator of
  physical or informational irreversibility."  (Rᵢ = True ⇔ irreversible.)
- IMPACT §13 — the reversible example outputs "Rᵢ = False".
- JUSTICE §3.1 — receives "Rᵢ — reversibility flags" from IMPACT.
- JUSTICE §6 (JUSTICE-6-01) — "Restitution applies when: impact is reversible (Rᵢ = True)".
- JUSTICE §8 (JUSTICE-8-01) — "Isolation applies when: impact is irreversible (Rᵢ = False)".

## Options for the author

| Option | Note |
|---|---|
| A. Rᵢ means irreversible (IMPACT §4, §13 stand); JUSTICE §6/§8 swap the parentheses | JUSTICE change |

| C. Rename to an unambiguous field (e.g. `irreversible`) in both | both texts change |
