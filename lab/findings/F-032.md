## Analysis

| | Rule A (Code A.4) | Rule B (SCOPE §3, S3) |
|---|---|---|
| Subject | the Council of Crisis Mercy | DKP execution ("algorithmic governance") |
| Object | control during Mercy; "discretionary decisions" | creation of discretionary emergency authorities |
| Scope | the Mercy events of A.4 | every protocol |
| Conditions | an event that triggers Mercy | none |
| Modality | automatic transfer of control | prohibition ("critical system violation") |

- **Joint compliance** is possible if the Council is not created by DKP execution (the Code establishes
  it in advance) or if its decisions are not discretionary.  It is impossible if the automatic
  transfer of control is DKP logic creating a discretionary emergency authority.
- **Priority.** A.4 itself places every discretionary decision of Mercy within SCOPE.  SCOPE §2 says
  SCOPE prevails in a conflict.  If the Council falls under S3, its discretionary decisions are void
  by the Code's own text.
- **Result.** It depends on the reading.  Also undefined: what "control" the Council holds beyond
  "response severity only".  A.4 names "suspensions" among Mercy actions, but the suspension of
  A.4's first sentence is automatic.
- **Related.** The "temporary manual control" of A.1a (F-030) raises the same question.
