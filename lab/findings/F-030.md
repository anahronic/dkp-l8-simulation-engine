# F-030 — A.1a "System Failure → temporary manual control": which violation counts, and what bounds the control

**Classification:** CONFIRMED_FINDING (kind `missing_definition`).  The bounds of the manual control are
defined nowhere; which violation is counted depends on the reading.  Open question Q-049.
**Found by:** module `code_synergy`.  **Regression:** `tests/lab/test_findings.py::test_f027_to_f032_code`.

## Verification against the pinned text

| Place | Literal text |
|---|---|
| Code A.1 | "At any moment in time *t*, the Network must maintain:" |
| Code A.1a | "All coefficients, bounds, and calibration parameters of the Main Equation SHALL NOT be optimized, tuned, or adjusted on-chain or through continuous execution." |
| Code A.1a | "Violation for more than 180 consecutive days = System Failure → Temporary manual control by the consortium of the first six nodes." |
| SCOPE §6 | "Any temporary authority, elevated control surface, or exceptional execution path:" … "MUST be time-bounded," |

**Searched** (all 39 pinned documents):
- Terms: "manual control", "consortium", "first six", "System Failure".
- All four occur in Code A.1a only.  No document gives the consortium's powers, the length of the
  control, its end or a return to automatic execution.

**Reference chain:**
- A.1a → A.5 (the six startup nodes; "first six" is not defined further).
- SCOPE §6 requires a temporary authority to be scoped, time-bounded and decaying.

What is missing or open:
1. **Which violation is counted.** The sentence closes A.1a, the parameter invariant, but it counts
   "consecutive days".  That fits the Main Equation, which must hold "At any moment in time t".  The
   two readings give different System Failures:
   - Main Equation: a world that misses dW/dt ≥ k·E·T·B^2.83 for 181 days.
   - Parameter invariant: a parameter changed outside UPGRADE stays in force for 181 days.
2. **Bounds of the manual control.** "Temporary" has no duration, no scope of powers and no end
   condition.  SCOPE §6 requires all three for any temporary authority.  Whether that control is a
   discretionary emergency authority under SCOPE S3 is the question of F-032.

## What the lab does

The lab declares System Failure only when both readings exceed 180 days.  It then marks the end of the
manual control as undefined.  When only one reading exceeds 180 days, it logs the state as
reading-dependent and reports UNKNOWN.
